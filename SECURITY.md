# Security Policy

## Supported Versions

Security fixes target the latest stable release on npm (`latest`). Fixes under validation may also appear in the newest preview release (`alpha`) before promotion to stable. Older releases are not actively maintained.

| Channel | Security support |
| --- | --- |
| Latest stable release | Supported |
| Newest preview release | Validation fixes only |
| Older releases | Upgrade to the latest stable release |

## Reporting a Vulnerability

For non-sensitive security issues, open a report at https://github.com/kenz1117/dsh-ui-usage-billing/issues with the affected plugin and DeepSeek Harness versions, reproduction steps, and expected impact.

For a sensitive vulnerability, open an issue containing only a request for a private security contact. Do not publish exploit details, credentials, session logs, prompts, or other user data; the maintainer can then arrange a private reporting channel.

Never include real API keys or other credentials in a report. Use synthetic fixtures for reproductions and rotate any credential that may have been exposed.
